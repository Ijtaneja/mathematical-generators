Mathematical Generators — Inder J. Taneja

Extract the whole ZIP, then open index.html for the site index and all generators. Keep the folders together.

The archive includes large data folders. Some generators load online libraries or fetch local data; these may need internet access or a local web server. If Python is installed, run start-server.py and open http://localhost:8000/.

The two HTML summaries remain separate downloads on your private downloads page.
