Crazy Power RepresentationsPyramid-Style Generator

Created by Inder J. Taneja

Write a number as ±0e₀ ± 1e₁ ± 2e₂ ± … ± keₖ, where the bases run 0, 1, …, k in order and the exponents are a permutation of the same digits 0, 1, …, k. Each row of the pyramid adds one more digit, up to k = 9.

Interval mode builds one pyramid per number, up to 300 numbers at a time.

Uses the sign and 00 options from the Pyramid tab. For each N it finds the smallest k and counts every representation at that k. Up to 20 000 numbers per scan. Click a row to open its pyramid.

The rule. For a chosen k, the bases are 0, 1, 2, …, k in this order. The exponents use every digit 0, 1, …, k exactly once, so each digit appears once as a base and once as a power. Only the signs between terms are free.

      
The pyramid. Starting from the smallest k that works for N, each new row uses one more digit. The last row, k = 9, uses all ten digits 0–9 twice.

      
Interval. In Interval mode the generator builds one pyramid for each N in the range, one below the other.

      
Search. Exponents are assigned from the largest base down. A branch is cut when the remaining target is larger than the biggest value the unused bases and exponents can still reach (largest exponent on the largest base). The full count at k = 9 takes well under a second.

      
Counting. A term 0e with e ≥ 1 is zero, so its sign does not create a new form; it is always shown with +. With "First term always +", the term 00 = 1 is never subtracted, matching the printed tables.

      
Example. 1089 = 01 + 10 + 23 + 34 + 45 − 52 is the only form of 1089 at k = 5.
