Selfie-Type Digit Power Sum
Number Generator

Created by Inder J. Taneja

Find all N where N = Σ ±dᵢ¹ + Σ ±dᵢ² + Σ ±dᵢ³

Rule: For a number N with digits d₁, d₂, …, dₖ — assign each digit a sign (+ or −) independently for each power level 1, 2, 3.
If the total equals N itself, it qualifies. Example: 336 = (3+3+6) + (3²+3²+6²) + (3³+3³+6³) = 12 + 54 + 270 = 336 ✓
Signed mode permits an independent + or − sign for every digit at every selected power. Results are shown once for each matching power.
