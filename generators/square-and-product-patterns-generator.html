The idea. Take a number, choose a digit and a place, and insert that digit 1, 2, 3, … times: 89 → 889, 8889, 88889, … (8s in front) or 89 → 869, 8669, 86669, … (6s in the middle). Square every row — or multiply it by a partner that grows the same way.

Two-block type. Each inserted digit adds exactly one more digit to two blocks of the answer, for ever: 689² = 474721, 6689² = 44742721, 66689² = 4447422721 … (one more 4 and one more 2). This happens when the inserted digit is 3, 6 or 9, because 33…3, 66…6 and 99…9 are multiples of 10ⁿ − 1 divided by 3, and their squares only need a division by 9.

Counting / pandigital type. The answer contains a run counting up and a run counting down, which together soon contain all ten digits: 888888889² = 79 0123456 987654321. This happens when the inserted digit is 1 or 8: 11…1² = 12345678987654321 is the source of the counting, and 88…8 = 8 × 11…1 with 8² = 64 = 1 + 7·9, so it carries the same counting. After nine or ten rows a carry breaks the runs.

Other digits (2, 4, 5, 7) give periodic blocks such as 049382716… instead; the search shows them only if they meet the chosen pattern type.

All arithmetic is exact (JavaScript BigInt), so every row shown is correct.
